En esta práctica se implementaron conceptos de Radio Definida por Software (SDR) utilizando la plataforma GNU Radio.
Se trabajó de forma colaborativa con GitHub para gestionar versiones y ramas, además se desarrollaron bloques en Python tales como:

-Acumulador

-Diferenciador

-Bloques estadísticos (media, media cuadrática, RMS, densidad espectral de potencia, desviación estándar)

Estos bloques fueron integrados en diagramas de flujo en GNU Radio junto con elementos como Vector Source, QT GUI Time Sink y QT GUI Number Sink, permitiendo analizar señales digitales en tiempo real.

La práctica tuvo como finalidad fortalecer el manejo de herramientas de procesamiento de señal, el trabajo en equipo, y la documentación técnica mediante lar Ramas de GitHub.
